FILUM portable browser

Start FILUM with Start-FILUM.cmd. The launcher keeps the browser profile and
temporary files beside this launcher, so the folder can be moved as a unit.

The profile includes preferences, extensions and their data, browsing history,
bookmarks, passwords, cookies and sessions. Keep the profile folder with the
browser folder when moving FILUM to another compatible Windows computer.

Do not launch browser.exe directly when you want to use the portable profile;
that bypasses the launcher and may use Gecko's normal Windows profile paths.
